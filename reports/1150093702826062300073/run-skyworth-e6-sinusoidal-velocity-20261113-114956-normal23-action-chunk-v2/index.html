Appendix · Calculation

计算公式与逻辑

  1. 位姿速度
    vi = pi − pi−1ti − ti−1

    机械臂保留 100 Hz 反馈；VR 保留手柄原生时间戳和原生频率。

  2. E6 墙钟映射
    thost = tsource + o + d · (tsource − tepoch)

    其中 o 为偏移量，d 为漂移系数，来自 USB CDC 四时间戳交换的稳健仿射拟合。

  3. 动态时延
    τ* = arg maxτ corr(vrobot(tVR − τ), RBWvVR(tVR))

    先将手柄运动旋转到机械臂基座系，再以手柄原生时间戳为采样网格，仅插值 100 Hz 机械臂反馈；搜索范围限制为 ±0.25 s，避免正弦波相邻周期峰混叠。

  4. 当前会话锚定
    TBW = mean(TBE · TEC · TWC−1)

    只使用开始阶段静止窗口重建本次 tracking session 的空间原点。

  5. 轨迹形状配准
    (R*, q*) = arg minR,q Σi ‖RpVR,i + q − probot,i‖2

    用 Kabsch 刚体配准移除新会话的整体坐标原点差异。

  6. 逐样本误差
    ei = ‖R*pVR,i + q* − probot,i‖ × 1000 mm
  7. Action Chunk 起点对齐
    A(t0) = TG(t0) TS(t0)−1，TalignedS(t) = A(t0) TS(t)

    每个窗口仅在起点对齐一次，此后固定变换；不重新搜索时间偏移，不使用整窗最优刚体配准。

  8. Action Chunk 终点误差
    EH(t0) = TG(t0 + H)−1 TalignedS(t0 + H)

    位置误差取平移向量模长，旋转误差取 SO(3) 旋转角；窗口内同时统计最大值和 RMS。

  9. 系统性与随机误差
    b(H) = mean(eH)，erandom = eH − b(H)

    有符号位置误差分别在真值坐标系和运动局部前向/横向/垂直坐标系报告；旋转使用 SO(3) 对数向量。

  10. 汇总统计
    mean = Σi eiN，RMSE = √Σi ei2N

    P95 为误差序列第 95 百分位，maximum 为最大值。
