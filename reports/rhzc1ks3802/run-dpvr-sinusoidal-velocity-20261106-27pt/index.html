结论

正式测试窗口内 455/455 条有效，无效 0 条；完整采集流为 655/878 条有效，无效 223 条。完整流失效原因：transform_read_failed 3 次；tracking_not_valid 199 次；source_time_not_advancing 21 次。

tracking_not_valid：设备已连接但 DPVR base_b_tracked=false，右手柄尚未完成定位追踪获取；source_time_not_advancing：SDK 源时间戳未推进，返回的是重复旧帧；transform_read_failed：桥接启动、连接或追踪状态切换瞬间位姿变换读取失败。原始记录不能证明头显或电脑进入休眠。

Appendix · Calculation

计算公式与逻辑

  1. 位姿速度
    vi = pi − pi−1ti − ti−1

    机械臂保留 100 Hz 反馈；VR 保留手柄原生时间戳和原生频率。

  2. DPVR 时间戳
    thost = tbefore + tafter2

    SDK 查询前后墙钟中点作为该次位姿的主机时间，并保留调用时延证据。

  3. 动态时延
    τ* = arg maxτ corr(vrobot(tVR − τ), RBWvVR(tVR))

    先将手柄运动旋转到机械臂基座系，再以手柄原生时间戳为采样网格，仅插值 100 Hz 机械臂反馈；搜索范围限制为 ±0.25 s，避免正弦波相邻周期峰混叠。

  4. 当前会话锚定
    TBW = mean(TBE · TEC · TWC−1)

    只使用开始阶段静止窗口重建本次 tracking session 的空间原点。

  5. 轨迹形状配准
    (R*, q*) = arg minR,q Σi ‖RpVR,i + q − probot,i‖2

    用 Kabsch 刚体配准移除新会话的整体坐标原点差异。

  6. 逐样本误差
    ei = ‖R*pVR,i + q* − probot,i‖ × 1000 mm
  7. 汇总统计
    mean = Σi eiN，RMSE = √Σi ei2N

    P95 为误差序列第 95 百分位，maximum 为最大值。
