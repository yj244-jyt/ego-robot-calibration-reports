01 · Decision

审计结论

DPVR 的优势没有被时间轴复算消除。
  • Quest 3 的可验证修正只有约 0.2–0.3 mm，不能解释其与 DPVR 的数毫米差距。
  • PICO、E6 和 DPVR 的候选固定偏移未通过两折留出验证，最终比较保留零偏移。
  • DPVR 在静态、统一 5 Hz 和速度匹配三项统计中都更低，当前数据支持真实跟踪收益，但仍需同日同轨迹受控复测才能做产品级排名。

05 · Transport assessment

四种采集链路判断

Quest 3 / PICO · WebXR 网页

电脑墙钟记录最新 WebXR 位姿的到达时间，可与机械臂对齐，但不等于手柄原生采样时刻。浏览器预测、网络和缓存共同形成有效 pose age。

Skyworth E6 · USB CDC

四时间戳同步把设备时钟映射到会话墙钟，映射残差可量化；但 nearest-render 语义仍不能分离位姿内部年龄。

DPVR · 本机原生 SDK

机械臂和 SDK 查询使用同机墙钟查询中点，并保留 SDK 单调源时间做新鲜度证据。跨时钟风险最低，但仍不是硬件融合时刻。

墙钟的边界

墙钟对齐只解决时钟域。设备内部预测、缓存与 pose age 必须依赖原生采样时间或独立运动验证。

07 · Controlled retest

后续受控复测计划

  1. 四设备运行同一条机械臂自动轨迹，固定速度、加速度、方向和持续时间。
  2. 同时保存主机接收时间、查询前后时间、设备原生单调时间和原始序列号。
  3. 每条轨迹分训练与验证两半，禁止根据最终误差反向挑选偏移。
  4. 统一按 5 Hz、相同有效间隔与相同速度分布统计，同时公布零偏移和已验证修正。
  5. 无法提供原生时间戳的设备只报告“有效运动延迟”，不宣称为内部采样延迟。
