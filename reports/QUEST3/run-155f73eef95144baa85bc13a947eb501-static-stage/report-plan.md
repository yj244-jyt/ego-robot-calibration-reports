### A. Effective Coverage Calculation / 有效覆盖率计算

令当前轨迹从正向回放起点到播放器时刻 $t$ 共有 $N_{\mathrm{candidate}}(t)$ 个公共时间轴候选样本，其中满足全部有效条件的样本数为 $N_{\mathrm{valid}}(t)$。实时有效覆盖率定义为：

$$
C(t)=\frac{N_{\mathrm{valid}}(t)}{N_{\mathrm{candidate}}(t)}\times 100\%.
$$

一个候选样本只有同时满足下列条件才记为有效：

- [ ] Robot 位姿存在且状态有效。
- [ ] Quest 右手柄位姿存在、跟踪有效且数据未过期。
- [ ] Robot 与 Quest 能够在公共时间轴上完成同步或插值。
- [ ] 插值跨度不超过分析配置中的 `max_interpolation_gap_ms`。
- [ ] `coordinate_epoch_id` 与本次冻结标定一致。
- [ ] 样本位于当前轨迹规定的统计窗口内。

无效原因必须按样本记录为 `robot_missing`、`quest_missing`、`tracking_invalid`、`stale_pose`、`interpolation_gap`、`epoch_mismatch` 或 `outside_window`。最终报告需保存各原因的数量，不能只保存一个覆盖率百分比。

### B. Linear Velocity Calculation / 线速度计算

Robot 和 Quest 必须表示同一个物理手柄坐标系 C。Robot 参考手柄位姿由机械臂末端位姿和冻结夹具变换得到：

$$
T_{BC,\mathrm{Robot}}(t)=T_{BE}(t)T_{EC}.
$$

Quest 观测手柄位姿使用冻结的 Robot 基座与 Quest world 变换转换到 B 系。完成坐标转换后，两路位姿再对齐到相同的公共时间轴 $t_k$，位置分别记为 $p_{\mathrm{Robot}}^B(t_k)$ 和 $p_{\mathrm{Quest}}^B(t_k)$。

内部样本采用相同的中心差分计算线速度大小：

$$
v_k=\frac{\left\lVert p(t_{k+1})-p(t_{k-1})\right\rVert_2}{t_{k+1}-t_{k-1}}.
$$

- [ ] Robot 实际速度使用 Robot 推算的手柄点 C，不直接使用法兰或 TCP 原点速度；夹具存在位置偏置时，转动会使两者线速度不同。
- [ ] Robot 与 Quest 必须使用相同的重采样频率、插值限制和差分窗口，避免计算方法本身造成速度差。
- [ ] 轨迹首尾在相邻样本有效且时间间隔合规时使用单边差分；条件不满足时标记为 `derivative_unavailable`，不复制相邻速度。
- [ ] 跨越无效样本或超限时间间隔时速度为 `null`，页面显示 `N/A`。
- [ ] Robot 控制器原生速度如可用，应作为审计字段保存；主对比仍使用与 Quest 相同的位姿差分方法。
- [ ] 报告来源信息记录 `resample_hz`、`max_interpolation_gap_ms`、`derivative_method`、`derivative_window_ms` 和任何滤波配置。
- [ ] 若使用滤波，Robot 与 Quest 使用相同方法和参数，同时保留未滤波速度，不允许只平滑其中一方。

播放器使用分析阶段预计算并保存的逐样本速度，不在浏览器中重新推导，保证播放器读数与最终统计完全一致。

### D. Translation Error / 平移误差计算

在同一公共时间 $t_k$ 和 Robot 基座 B 系下：

$$
e_{p,k}=1000\left\lVert p_{\mathrm{Quest}}^B(t_k)-p_{\mathrm{Robot}}^B(t_k)\right\rVert_2\ \mathrm{mm}.
$$

### E. Rotation Error / 旋转误差计算

令归一化四元数分别为 $q_{\mathrm{Robot},k}$ 和 $q_{\mathrm{Quest},k}$，四元数顺序固定为 `(x, y, z, w)`。旋转误差使用相对旋转的测地角：

$$
e_{R,k}=2\arccos\left(\operatorname{clamp}\left(\left\lvert q_{\mathrm{Robot},k}\cdot q_{\mathrm{Quest},k}\right\rvert,0,1\right)\right)\frac{180}{\pi}\ \mathrm{deg}.
$$

绝对值处理 $q$ 与 $-q$ 表示同一旋转的问题。不得使用欧拉角逐轴相减代替该指标。

### F. Summary Statistics / 汇总统计计算

对某分区内的 $N$ 个有效误差样本 $e_i$，统一计算：

$$
\operatorname{Mean}=\frac{1}{N}\sum_{i=1}^{N}e_i,
$$

$$
\operatorname{RMSE}=\sqrt{\frac{1}{N}\sum_{i=1}^{N}e_i^2}.
$$

中位数、P95 和最大值均在同一有效样本集合上计算。统计前不得用零填充无效样本，也不得为改善结果而删除真实的大误差有效样本。

## 9. Acceptance Checklist / 验收清单

### A. Visualization / 可视化

- [ ] 有速度数据时，轨迹可视化明确出现“线速度测试”选项。
- [ ] 可分别选择并回放 `0.5 / 1.0 / 1.5 m/s` 轨迹。
- [ ] 原有测试的选择和回放行为没有变化。
- [ ] 右上角始终显示有效覆盖率、Robot 实际速度和 Quest 估计速度。
- [ ] 播放、暂停和拖动时间轴后，三个实时读数与当前画面时间一致。
- [ ] 离线打开 HTML 后，上述选择、回放和实时读数全部可用。

### B. Data Integrity / 数据完整性

- [ ] 每个播放器样本可追溯到 Robot 与 Quest 原始记录、标定包和事件窗口。
- [ ] 覆盖率的分子、分母和无效原因均被保存并可复算。
- [ ] Robot 和 Quest 速度使用相同时间轴和差分方法。
- [ ] 自动回起点和终点静止数据不进入速度统计。
- [ ] 缺失、失效和不可计算数据保持为空并显示原因，不填零。
- [ ] 页面读数、单段明细和最终统计由同一分析结果生成。

### C. Final Statistics / 最终统计

- [ ] 最终统计恰好分为静态、连续轨迹和速度三部分。
- [ ] 三部分都分别统计平移误差和旋转误差。
- [ ] 每类误差均显示平均、RMSE、中位数、P95、最大值和样本数。
- [ ] 每部分同时显示有效覆盖率或跟踪有效率。
- [ ] 速度部分按三个速度档分别统计，不生成掩盖档位差异的合并主指标。
- [ ] 没有原生 Quest 时间戳时，速度部分明确显示 `continuous_trajectory_diagnostic`。
